# KPE Optimizer (Itel 50)

Simple Android optimizer. No root.

- Boost: stops background processes of your apps (killBackgroundProcesses)
- Stop button per app
- Tap app name: open app settings (Force stop)
- Notification blocker: removes notifications of your apps. Never calls, alarms, system apps.
- Shortcuts: battery optimization, running services, storage

## Build
Option 1: Open folder in Android Studio, press Run / Build > Build APK.
Option 2: Push to GitHub. Actions > Build APK > download app-debug.apk.

## Notification blocker setup
Android 13+ blocks this for installed APK files. If access is greyed out:
Settings > Apps > KPE Optimizer > menu (3 dots) > Allow restricted settings.
Then turn on KPE Optimizer in Notification access.
